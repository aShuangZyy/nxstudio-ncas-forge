# 安全、隐私与合规

## 这个项目做什么 / 不做什么

| 做 | 不做 |
|---|---|
| 在本机起一个只拦 `*.cld.nikon.com` 的小代理 | 不修改、不重打包、不分发任何 Nikon 文件 |
| 用本机自签 CA 对那两个域名终止 TLS，返回伪造的"成功"响应 | 不连接、不攻击、不探测尼康服务器（命中规则的请求**不会转发**） |
| 把伪造的会话物料交给 app，让它正常创建主窗口 | 不提供、不包含任何真实账号、密码或令牌 |
| 提供一键卸载（移除 CA、还原代理、删生成物） | 不申请管理员权限、不写系统级目录 |

## 隐私

- 仓库内**没有任何真实账号标识、令牌、厂商内部凭据或抓包日志**；开发期观察到的值一律以占位符（`00000000-0000-4000-8000-0000000000aa` 等）代替。
- `certs/`（含 CA/叶私钥）、`rules.json`、`logs/` 全部由 `setup.ps1` 在你本机生成，且已在 `.gitignore` 中——**不要把它们提交或分享**。
- 代理只监听 `127.0.0.1`，不对外网开放；不采集遥测、不上传任何数据。
- 排障日志可能包含请求头（例如 `authorization` 的前若干字符）。要外发请先自行脱敏。

## 信任边界

`setup.ps1` 会把一个**仅用于本机测试**的自签 CA 装进**当前用户**的根证书存储。这意味着：
在它被信任期间，能拿到 `certs/leaf.key.pem` 的一方可以对该 CA 覆盖的域名（配置见 `scripts/mkcerts.py` 的 `HOSTS`）伪造证书。
所以请把 `certs/` 当成敏感目录；不再使用就运行 `uninstall.ps1`（或至少 `certutil -user -delstore Root NX-Forge-CA`）。
