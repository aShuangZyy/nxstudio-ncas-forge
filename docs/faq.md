# 常见问题

**Q0：需要管理员权限吗？**
不需要。CA 只装进 `Cert:\CurrentUser\Root`，代理设置写在 `HKCU`。

**Q1：跑完了，登录框还是出现。**
按顺序查：
1. `check.ps1` 是否全绿（尤其 "CA trusted" 与 "forged response"）。
2. 系统代理有没有被别的软件抢走（Clash / 公司代理 / VPN 常驻会覆盖 `HKCU` 的代理设置）。把它们的"系统代理"关掉，或把 `*.cld.nikon.com` 加到它们的直连白名单。
3. `rules.json` 里的 `response_code` 必须是 `"0000"`（不是 `"E0000"`）。改了之后重跑 `start-nxstudio.ps1`。
4. 看 `logs/mitm-*.log`：如果一笔 nikon 请求都没有，说明流量没进代理；如果有请求但没出现 `forged`/`rule=`，说明主机/路径没匹配上（新版改协议了，按 [how-it-works.md](how-it-works.md) 第 6 节加规则）。

**Q2：会不会影响浏览器 / 其它程序？**
不会。只有 `*.cld.nikon.com` 被 TLS 终止并伪造，其它域名走盲隧道（只转发原始字节），证书正常。

**Q3：云功能怎么用不了？**
伪造会话只保证"能进主界面"，云同步一类需要真实账号数据的接口会拿到占位的成功响应。本地浏览、调整、导出正常。

**Q4：为什么每次都要先起这个代理？**
因为我们不修改 NX Studio 的文件。代理不在，app 就按原逻辑走（弹登录框）。想省事就用 `make-shortcut.ps1` 生成的桌面图标，它会自动管代理的生命周期。

**Q5：NX Studio 升级后失效了怎么办？**
先跑 `check.ps1`，再看日志里新增/变化的请求。多数情况只需要在 `rules.json` 里补一条规则。

**Q6：怎么彻底回滚？**
`uninstall.ps1`：停代理、关系统代理、移除 `NX-Forge-CA`、删掉 `certs/ rules.json logs/`。NX Studio 会恢复"要登录"的状态。

**Q7：会不会把账号密码发给谁？**
不会。app 发往尼康的那两笔请求被本机拦下、**不会转发**给真实服务器（规则命中即本地应答）；本机代理不收集、不上传任何数据，日志只写在你自己的 `logs/` 里。

**Q8：`secret_key` / 密码 / 令牌出现在日志里吗？**
`mitm.py` 会为排障打印请求头与请求体（含 `authorization` 前 40 字符）。如果你把日志发人，请先自行脱敏；`logs/` 默认被 `.gitignore` 忽略。
